Python is one of the most popular languages in fresher interviews for developer, data and AI roles. Interviewers usually test fundamentals first, then move to functions, OOP and a few coding problems. These 50 Python interview questions cover the topics asked most often, with short answers you can understand and explain in your own words.

Python basics

1. What is Python?

Python is a high-level, interpreted, general-purpose programming language known for readable syntax. It supports procedural, object-oriented and functional programming and is used in web development, automation, data science and AI.

2. What are the key features of Python?

Simple syntax, dynamic typing, automatic memory management, a large standard library, cross-platform support, and a huge ecosystem of third-party packages.

3. Is Python compiled or interpreted?

The standard implementation, CPython, compiles source code to bytecode, which is then executed by the Python virtual machine. It is usually described as interpreted because there is no separate compile step for the programmer.

4. What is PEP 8?

PEP 8 is the official style guide for Python code. It covers naming, indentation (four spaces), line length, imports and spacing to keep code consistent and readable.

5. What is dynamic typing?

Variable types are determined at run time, not declared in advance. The same name can refer to an integer and later to a string. Type hints can be added for readability and tooling, but Python does not enforce them at run time.

6. How is indentation used in Python?

Indentation defines code blocks (in loops, functions, classes and conditionals) instead of braces. Incorrect indentation causes an IndentationError.

7. What are Python's built-in data types?

Numbers (int, float, complex), str, bool, sequences (list, tuple, range), mappings (dict), sets (set, frozenset), bytes and NoneType.

8. What is the difference between mutable and immutable types?

Mutable objects can be changed after creation (list, dict, set). Immutable objects cannot (int, float, str, tuple, frozenset). "Changing" an immutable object actually creates a new one.

Data structures

9. What is the difference between a list and a tuple?

Lists are mutable and use square brackets; tuples are immutable and use parentheses. Tuples can be used as dictionary keys (if their contents are hashable), and they communicate that data should not change.

10. How do you remove duplicates from a list?

list(set(items)) removes duplicates but loses order. To keep order: list(dict.fromkeys(items)).

11. What is a dictionary? How do you access values safely?

A dictionary stores key–value pairs with fast lookups. Use d.get(key, default) to avoid a KeyError when the key may be missing.

12. What are list comprehensions?

A concise way to build lists: [x * x for x in range(10) if x % 2 == 0]. Similar syntax exists for dictionaries and sets.

13. What is slicing?

Extracting part of a sequence with seq[start:stop:step]. For example, s[::-1] reverses a string or list.

14. What is the difference between a set and a list?

A set stores unique, unordered elements and offers fast membership tests. A list is ordered, allows duplicates and supports indexing.

15. What is the difference between append() and extend()?

append(x) adds x as one element. extend(iterable) adds each element of the iterable.

Functions

16. What are *args and **kwargs?

*args collects extra positional arguments into a tuple; **kwargs collects extra keyword arguments into a dictionary.

def show(*args, **kwargs):
    print(args, kwargs)

show(1, 2, course="Python")   # (1, 2) {'course': 'Python'}

17. What is a lambda function?

A small anonymous function written in one expression: square = lambda x: x * x. Often used with sorted, map and filter.

18. What is the problem with mutable default arguments?

Default values are evaluated once, when the function is defined. A mutable default like def add(item, items=[]) is shared between calls. Use items=None and create a new list inside the function.

19. Explain map(), filter() and reduce().

map applies a function to every item, filter keeps items for which a function returns true, and functools.reduce combines items into a single value.

20. What is the scope of a variable? What is the LEGB rule?

Python looks up names in this order: Local, Enclosing, Global, Built-in. Use global or nonlocal to assign to outer variables.

21. What is a decorator?

A function that takes another function and extends its behaviour without changing its code.

import time
from functools import wraps

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} took {time.perf_counter() - start:.3f}s")
        return result
    return wrapper

@timer
def slow():
    time.sleep(0.5)

22. What is a closure?

A nested function that remembers variables from its enclosing function even after the outer function has returned.

Iterators and generators

23. What is the difference between an iterable and an iterator?

An iterable can be looped over (it has __iter__). An iterator produces values one at a time with __next__ and remembers its position.

24. What is a generator?

A function that uses yield to produce values lazily, one at a time, saving memory.

def countdown(n):
    while n > 0:
        yield n
        n -= 1

for x in countdown(3):
    print(x)   # 3, 2, 1

25. What is the difference between return and yield?

return ends the function and sends back one value. yield pauses the function, produces a value and resumes from the same point on the next request.

Object-oriented programming

26. What is __init__?

The initialiser method that runs when an object is created, used to set initial attributes.

27. What is self?

A reference to the current instance, passed automatically as the first argument to instance methods.

28. Explain inheritance in Python.

A class can inherit attributes and methods from another: class Manager(Employee):. Python supports multiple inheritance and resolves method lookup using the Method Resolution Order (MRO).

29. What is the difference between @staticmethod and @classmethod?

A static method receives no automatic first argument and behaves like a normal function inside the class. A class method receives the class (cls) and is often used for alternative constructors.

30. What are dunder (magic) methods?

Special methods with double underscores, such as __str__, __repr__, __len__, __eq__ and __add__, that let objects work with built-in functions and operators.

31. What is the difference between __str__ and __repr__?

__str__ returns a readable string for users; __repr__ returns an unambiguous representation for developers, ideally one that could recreate the object.

32. How does Python support encapsulation?

By convention: a single underscore (_balance) signals "internal use", and a double underscore (__balance) triggers name mangling. Properties (@property) provide controlled access.

Exceptions and files

33. How does exception handling work?

Code that may fail goes in try; specific errors are handled in except; else runs if no error occurred; finally always runs.

34. How do you raise a custom exception?

class InsufficientBalance(Exception):
    pass

raise InsufficientBalance("Balance too low")

35. What is a context manager?

An object used with with that sets up and cleans up resources automatically, such as closing files: with open("data.txt") as f:.

Modules and memory

36. What is the difference between a module and a package?

A module is a single .py file. A package is a directory of modules (traditionally with an __init__.py file).

37. What does if __name__ == "__main__": do?

It runs the block only when the file is executed directly, not when it is imported as a module.

38. How is memory managed in Python?

CPython uses reference counting plus a cyclic garbage collector to free objects that are no longer used. Memory is managed in a private heap.

39. What is the difference between shallow copy and deep copy?

A shallow copy (copy.copy) copies the outer object but shares nested objects. A deep copy (copy.deepcopy) recursively copies everything.

40. What is the difference between is and ==?

== compares values; is checks whether two names refer to the same object. Use is for None checks: if x is None.

Advanced concepts

41. What is the GIL?

The Global Interpreter Lock in CPython allows only one thread to execute Python bytecode at a time. Threads still help with I/O-bound work; for CPU-bound work, use multiprocessing or libraries that release the GIL. Recent Python versions also offer an experimental free-threaded build.

42. What is the difference between multithreading and multiprocessing?

Threads share memory within one process and suit I/O-bound tasks. Processes have separate memory, can run on multiple CPU cores in parallel, and suit CPU-bound tasks.

43. What is async/await?

Syntax for asynchronous programming with asyncio, letting one thread handle many I/O operations (such as network requests) concurrently.

44. What are virtual environments?

Isolated environments (created with python -m venv) that keep each project's dependencies separate.

45. What are type hints?

Optional annotations like def add(a: int, b: int) -> int: that improve readability and allow static checkers to find bugs.

Coding questions

46. Reverse a string.

def reverse(s):
    return s[::-1]

47. Check whether a string is a palindrome.

def is_palindrome(s):
    cleaned = "".join(ch.lower() for ch in s if ch.isalnum())
    return cleaned == cleaned[::-1]

48. Count the frequency of each character.

from collections import Counter
print(Counter("programming"))

49. Find the second largest number in a list.

def second_largest(nums):
    unique = sorted(set(nums))
    return unique[-2] if len(unique) >= 2 else None

50. Find two numbers in a list that add up to a target.

def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        if target - n in seen:
            return seen[target - n], i
        seen[n] = i
    return None

This runs in O(n) time using a dictionary, a solution interviewers love to see, compared with the O(n²) nested-loop approach.

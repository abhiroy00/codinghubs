If you repeat the same task on a computer every day or every week, Python can probably do it for you. Python automation is one of the most practical uses of the language: a few lines of code can save hours of copying, renaming, formatting and clicking. Here are ten useful scripts, each with the idea, the key libraries and a short example.

Before you start

Use Python 3 and create a virtual environment for your automation scripts. Always test scripts on a copy of your files first, and keep backups. Automation is powerful, which means mistakes are fast too.

1. Organise your Downloads folder

Move files into folders based on their extension.

from pathlib import Path
import shutil

downloads = Path.home() / "Downloads"
groups = {"Images": [".jpg", ".png", ".webp"], "Docs": [".pdf", ".docx", ".xlsx"], "Videos": [".mp4", ".mov"]}

for file in downloads.iterdir():
    if file.is_file():
        for folder, extensions in groups.items():
            if file.suffix.lower() in extensions:
                target = downloads / folder
                target.mkdir(exist_ok=True)
                shutil.move(str(file), target / file.name)

2. Rename files in bulk

Rename hundreds of photos or documents with a consistent pattern, such as invoice-001.pdf, invoice-002.pdf.

from pathlib import Path

folder = Path("invoices")
for i, file in enumerate(sorted(folder.glob("*.pdf")), start=1):
    file.rename(folder / f"invoice-{i:03}.pdf")

3. Generate Excel reports automatically

Combine several CSV or Excel files, calculate totals and save a formatted report with pandas.

import pandas as pd
from pathlib import Path

frames = [pd.read_csv(f) for f in Path("sales").glob("*.csv")]
sales = pd.concat(frames)
summary = sales.groupby("region")["amount"].sum().reset_index()
summary.to_excel("monthly_summary.xlsx", index=False)

You will need pandas and openpyxl installed.

4. Send emails automatically

Send reports or reminders using Python's built-in smtplib and email modules. Store your email password or app password in an environment variable, never in the script itself. Many email providers require an app-specific password for this.

5. Merge or split PDFs

Combine monthly statements into one file, or extract specific pages, using the pypdf library.

from pypdf import PdfWriter

writer = PdfWriter()
for name in ["jan.pdf", "feb.pdf", "mar.pdf"]:
    writer.append(name)
writer.write("q1_statements.pdf")

6. Resize and compress images

Use the Pillow library to resize product photos, convert formats or create thumbnails for a website. This is especially useful for making web pages load faster.

7. Collect data from websites

Use requests and BeautifulSoup to collect information such as product prices or public notices, then save it to a spreadsheet. Respect each website's terms of use and robots.txt, and prefer official APIs when they exist.

8. Automate browser tasks

Tools like Playwright and Selenium control a real browser: logging in, filling forms, downloading reports and taking screenshots. They are widely used for testing and for repetitive web tasks inside companies.

9. Back up important folders

Create a dated zip archive of a folder every day.

import shutil
from datetime import date

shutil.make_archive(f"backup-{date.today()}", "zip", "important_files")

10. Summarise documents with AI

Combine automation with a large language model API to summarise long reports, extract key points from emails, or draft replies. Read files with Python, send the text to the model with clear instructions, and save the result. Always review AI output before sharing it, and never send confidential data to an external service without permission.

Schedule your scripts

Automation is most useful when it runs without you:

  • Windows: use Task Scheduler to run python script.py at set times.
  • macOS and Linux: use cron, for example running a backup every night.
  • In Python: the schedule library works for simple, always-running scripts.

Best practices for automation scripts

  • Log what the script does, so you can check it later.
  • Add a "dry run" mode that prints planned actions without making changes.
  • Handle errors gracefully and skip problem files instead of crashing.
  • Keep passwords and API keys in environment variables.
  • Store scripts in Git so you can track changes.

===FAQ=== Q: What can I automate with Python? A: You can automate file organisation, renaming, Excel and CSV reports, emails, PDF handling, image processing, web data collection, browser tasks, backups and many other repetitive computer tasks. Q: Is Python good for automation? A: Yes. Python's simple syntax and large library ecosystem make it one of the most popular languages for automation and scripting. Q: Do I need to be an expert to automate tasks with Python? A: No. Basic Python knowledge such as variables, loops, functions and file handling is enough to write many useful automation scripts. Q: Is web scraping legal? A: It depends on the website's terms, the data being collected and local laws. Check terms of use and robots.txt, avoid personal data, and prefer official APIs.

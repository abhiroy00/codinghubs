Python is often the first language people learn, and it is easy to see why. The code is short and readable, mistakes are easy to understand, and you can do useful things within days. If you want to learn Python for beginners style, starting from absolutely nothing, this 30-day plan gives you one clear goal per stage, with examples you can type and run yourself.

Before you start

You need a computer (Windows, macOS or Linux), an internet connection, and about one hour a day. Install Python 3 from python.org (on Windows, tick "Add Python to PATH" during installation) and a code editor such as VS Code with the Python extension. Check the installation in a terminal:

python --version

If you see a version number starting with 3, you are ready.

Days 1–3: Your first programs

Create a file called hello.py and run it with python hello.py:

print("Hello, World!")
name = input("What is your name? ")
print(f"Welcome to Python, {name}!")

Learn what print and input do, and how f-strings put variables inside text. Then learn comments (lines starting with #) to explain your code.

Days 4–6: Variables and data types

A variable is a name that refers to a value. Python works out the type automatically:

age = 21            # int
price = 499.99      # float
city = "Delhi"      # str
is_student = True   # bool

print(type(price))  # <class 'float'>

Practise converting between types with int(), float() and str(). Remember that input() always returns text, so convert it before doing maths.

Days 7–9: Operators and conditions

Learn arithmetic operators (+ - * / // % **), comparison operators (== != < > <= >=) and logical operators (and, or, not). Then make decisions with if:

marks = int(input("Enter your marks: "))
if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
else:
    print("Keep practising!")

Notice the indentation. Python uses spaces (normally four) to show which lines belong inside a block.

Days 10–12: Loops

Loops repeat work. Use for when you know how many times, and while when you repeat until something changes:

for i in range(1, 6):
    print(i, "x 7 =", i * 7)

password = ""
while password != "python123":
    password = input("Password: ")
print("Access granted")

Learn break and continue, and practise by printing patterns, multiplication tables and sums of numbers.

Days 13–15: Functions

Functions package code you want to reuse:

def is_even(number):
    return number % 2 == 0

print(is_even(10))  # True

Learn parameters, return values, default arguments and the difference between local and global variables. Rewrite earlier exercises using functions.

Days 16–19: Lists and tuples

Lists store ordered collections that can change:

fruits = ["apple", "banana", "mango"]
fruits.append("orange")
print(fruits[0])      # apple
print(fruits[-1])     # orange
print(len(fruits))    # 4

squares = [n * n for n in range(1, 6)]   # list comprehension

Learn indexing, slicing, sorting, looping through lists and list comprehensions. Tuples are like lists but cannot be changed, which makes them useful for fixed data such as coordinates.

Days 20–22: Dictionaries and sets

Dictionaries store key–value pairs, perfect for looking things up:

student = {"name": "Riya", "course": "Python", "marks": 88}
print(student["name"])
student["marks"] = 92

for key, value in student.items():
    print(key, ":", value)

Sets store unique values and are great for removing duplicates: set([1, 2, 2, 3]) gives {1, 2, 3}.

Days 23–25: Strings and error handling

Practise string methods such as upper(), lower(), strip(), split(), replace() and join(). Then learn to handle errors so your program does not crash:

try:
    number = int(input("Enter a number: "))
    print(100 / number)
except ValueError:
    print("That is not a number.")
except ZeroDivisionError:
    print("You cannot divide by zero.")

Days 26–27: Files and modules

Read and write files with with open(...), which closes the file automatically. Then import modules from the standard library, such as random, math and datetime, and install a third-party package with pip.

with open("notes.txt", "a") as file:
    file.write("Learned file handling today\n")

Days 28–30: Mini projects

Put everything together. Choose two or three:

  • Number guessing game using random and loops.
  • Simple calculator with functions and error handling.
  • To-do list that saves tasks to a file.
  • Student marks report using dictionaries and averages.
  • Password generator using random and strings.

Push your projects to GitHub so you can see your progress and share it later.

Tips that make learning stick

  • Type the code yourself instead of copying and pasting.
  • Change examples and predict the output before running them.
  • When you get an error, read the last line first; it usually names the problem.
  • Explain what you learned each day in two or three sentences.

What to learn after 30 days

Next, learn object-oriented programming, then choose a direction: web development with Django or FastAPI, data analysis with pandas, automation, or AI. Read our Python developer roadmap for the full path, or try some Python projects for beginners.

===FAQ=== Q: Can I learn Python in 30 days? A: You can learn Python basics in 30 days with about an hour of practice daily. Becoming job-ready takes longer, because you also need projects, a specialisation and problem-solving practice. Q: Is Python easy for complete beginners? A: Yes. Python has simple, readable syntax and clear error messages, which makes it one of the easiest programming languages to start with. Q: Do I need a powerful laptop to learn Python? A: No. Any modern laptop or desktop that can run a web browser and a code editor is enough to learn Python. Q: What should I build after learning Python basics? A: Start with small projects such as a calculator, to-do app or quiz game, then move to web apps, automation scripts or data analysis projects.

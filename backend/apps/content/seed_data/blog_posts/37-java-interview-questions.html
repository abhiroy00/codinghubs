Java remains one of the most common languages in fresher hiring, especially at IT services and enterprise companies. Interviews usually start with Core Java and OOP, then move to strings, collections, exceptions and a few coding problems. Here are 40 frequently asked Java interview questions with concise answers to help you prepare.

Java basics

1. What are the main features of Java?

Object-oriented, platform-independent through bytecode and the JVM, strongly and statically typed, automatic memory management, built-in multithreading, and a rich standard library.

2. What is the difference between JDK, JRE and JVM?

The JVM runs bytecode. The JRE contains the JVM plus core libraries to run programs. The JDK contains the JRE plus development tools such as the compiler.

3. Why is Java platform-independent?

Java source code compiles to bytecode, which runs on any device with a compatible JVM, regardless of operating system.

4. Why is the main method public static void?

public so the JVM can call it, static so it can run without creating an object, and void because it returns nothing to the JVM.

5. What are primitive data types in Java?

byte, short, int, long, float, double, char and boolean.

6. What are wrapper classes and autoboxing?

Wrapper classes (Integer, Double, etc.) represent primitives as objects. Autoboxing converts primitives to wrappers automatically; unboxing does the reverse.

7. Is Java pass-by-value or pass-by-reference?

Java is always pass-by-value. For objects, the value passed is a copy of the reference, so a method can modify the object's contents but cannot make the caller's variable point to a different object.

Object-oriented programming

8. What are the four pillars of OOP?

Encapsulation, inheritance, polymorphism and abstraction. See OOP concepts in Java for detailed examples.

9. What is the difference between method overloading and overriding?

Overloading: same method name, different parameter lists, in the same class, resolved at compile time. Overriding: a subclass redefines a parent method with the same signature, resolved at run time.

10. What is the difference between an abstract class and an interface?

An abstract class can have state, constructors and both abstract and concrete methods; a class can extend only one. An interface defines a contract with abstract, default and static methods and constants; a class can implement many.

11. Why doesn't Java support multiple inheritance of classes?

To avoid ambiguity such as the "diamond problem", where two parent classes provide different implementations of the same method. Multiple interfaces are allowed instead.

12. What is a constructor? Can it be private?

A constructor initialises a new object and has the same name as the class with no return type. It can be private, for example in the Singleton pattern or utility classes.

13. What does the static keyword mean?

Static members belong to the class rather than to any instance. Static methods cannot access instance variables directly.

14. What does final mean for variables, methods and classes?

A final variable cannot be reassigned, a final method cannot be overridden, and a final class cannot be extended.

15. What is the difference between this and super?

this refers to the current object; super refers to the parent class and is used to call parent constructors or methods.

Strings

16. Why are strings immutable in Java?

For security, thread safety, caching of hash codes and the string constant pool, which lets identical literals share memory safely.

17. What is the difference between String, StringBuilder and StringBuffer?

String is immutable. StringBuilder is mutable and fast but not thread-safe. StringBuffer is mutable and synchronised (thread-safe) but slower.

18. What is the difference between == and equals()?

== compares references for objects; equals() compares logical content when overridden, as in String.

19. What is the string constant pool?

A special memory area where string literals are stored so that identical literals share a single object.

Exceptions

20. What is the difference between checked and unchecked exceptions?

Checked exceptions (such as IOException) must be caught or declared. Unchecked exceptions (subclasses of RuntimeException, such as NullPointerException) need not be.

21. What is the difference between throw and throws?

throw actually throws an exception object. throws in a method signature declares exceptions the method might throw.

22. Does finally always execute?

Almost always, even when an exception occurs or a return is reached. It does not run if the JVM exits (for example with System.exit()) or crashes.

23. What is try-with-resources?

A try statement that automatically closes resources implementing AutoCloseable, such as files and database connections.

Collections

24. What is the difference between ArrayList and LinkedList?

ArrayList uses a resizable array with fast index access. LinkedList uses a doubly linked list with efficient insertions and removals at the ends but slow index access.

25. How does HashMap work internally?

It hashes the key to choose a bucket, stores entries there, uses equals() to resolve collisions, converts large buckets to balanced trees (Java 8+), and resizes when the load factor is exceeded. Details are in our Java Collections Framework guide.

26. What is the difference between HashMap and ConcurrentHashMap?

HashMap is not thread-safe. ConcurrentHashMap supports safe concurrent access with fine-grained locking and is preferred for shared maps in multithreaded code.

27. What is the difference between HashSet and TreeSet?

HashSet offers fast operations with no ordering. TreeSet keeps elements sorted with O(log n) operations.

28. What is the difference between Comparable and Comparator?

Comparable defines a class's natural ordering through compareTo(). Comparator defines separate, custom orderings through compare().

29. What is a fail-fast iterator?

An iterator that throws ConcurrentModificationException if the collection is structurally modified during iteration, except through the iterator's own remove().

Multithreading

30. How can you create a thread in Java?

By extending Thread, implementing Runnable or Callable, or, preferably, submitting tasks to an ExecutorService. Modern Java also offers virtual threads for large numbers of concurrent tasks.

31. What is synchronisation?

A mechanism (the synchronized keyword or locks) that allows only one thread at a time to access a critical section, preventing race conditions.

32. What is a deadlock?

A situation where two or more threads wait forever for locks held by each other. Avoid it by acquiring locks in a consistent order and using timeouts.

33. What is the volatile keyword?

It guarantees that reads and writes of a variable go to main memory, so changes made by one thread are visible to others. It does not make compound operations atomic.

Java 8 and modern Java

34. What are lambda expressions?

Concise anonymous functions, such as (a, b) -> a + b, used to implement functional interfaces.

35. What is a functional interface?

An interface with exactly one abstract method, such as Runnable, Predicate or Function, optionally marked @FunctionalInterface.

36. What is the Stream API?

An API for processing collections declaratively with operations like filter, map, sorted and collect.

37. What is Optional?

A container that may or may not hold a value, used to avoid null checks and NullPointerException.

Coding questions

38. Reverse a string without using reverse().

static String reverse(String s) {
    char[] chars = s.toCharArray();
    for (int i = 0, j = chars.length - 1; i < j; i++, j--) {
        char tmp = chars[i];
        chars[i] = chars[j];
        chars[j] = tmp;
    }
    return new String(chars);
}

39. Count character occurrences in a string.

Map<Character, Integer> counts = new HashMap<>();
for (char c : "programming".toCharArray()) {
    counts.merge(c, 1, Integer::sum);
}

40. Find duplicate elements in an array.

static Set<Integer> duplicates(int[] nums) {
    Set<Integer> seen = new HashSet<>();
    Set<Integer> dups = new HashSet<>();
    for (int n : nums) {
        if (!seen.add(n)) dups.add(n);
    }
    return dups;
}

  • Know your projects: architecture, challenges and what you would improve.

Web development courses: what you will learn

Web development is usually taught in three layers:

  1. Front end: HTML, CSS and JavaScript, then a framework such as React, to build what users see and click.
  2. Back end: a server language and framework (Node.js with Express, Python with Django, or Java with Spring Boot) to handle logic, logins and data.
  3. Database and deployment: SQL or MongoDB, Git, and putting your project online.

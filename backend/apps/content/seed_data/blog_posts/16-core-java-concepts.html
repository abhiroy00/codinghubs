Whether you want to become a Java developer, a Java full stack developer or an Android developer, everything rests on Core Java. These are also the topics that appear again and again in fresher interviews. This guide covers the essential core Java concepts with short explanations and examples you can run.

1. JDK, JRE and JVM

  • JVM (Java Virtual Machine): runs Java bytecode. It is why Java is "write once, run anywhere": the same bytecode runs on any operating system with a JVM.
  • JRE (Java Runtime Environment): the JVM plus the core libraries needed to run Java programs.
  • JDK (Java Development Kit): the JRE plus development tools such as the compiler javac. Developers install the JDK.

When you compile Main.java, javac produces Main.class (bytecode), which the JVM executes.

2. Data types and variables

Java has eight primitive types: byte, short, int, long, float, double, char and boolean. Everything else is a reference type, such as String, arrays and objects. Each primitive has a wrapper class (Integer, Double and so on), and Java converts between them automatically through autoboxing and unboxing.

int age = 22;
double fee = 15999.50;
char grade = 'A';
boolean placed = true;
Integer boxed = age;   // autoboxing

3. Control flow

Learn if-else, switch (including the newer switch expressions), for, enhanced for, while and do-while loops, and break and continue. These are the building blocks of every program.

4. Classes and objects

A class is a blueprint; an object is an instance of that blueprint.

class Student {
    private String name;
    private int marks;

    Student(String name, int marks) {
        this.name = name;
        this.marks = marks;
    }

    boolean hasPassed() {
        return marks >= 40;
    }
}

Student s = new Student("Aman", 72);
System.out.println(s.hasPassed());   // true

Understand constructors, the this keyword, constructor overloading and how objects live on the heap while references live on the stack.

5. The four pillars of OOP

  • Encapsulation: hide data with private fields and expose controlled access through methods.
  • Inheritance: a class reuses another with extends. Java supports single inheritance of classes.
  • Polymorphism: overloading (same method name, different parameters, decided at compile time) and overriding (a subclass redefines a parent method, decided at run time).
  • Abstraction: expose what an object does, not how, using abstract classes and interfaces.

Read our detailed guide on OOP concepts in Java for examples of each.

6. Important keywords

  • static: belongs to the class rather than an object.
  • final: a final variable cannot be reassigned, a final method cannot be overridden, a final class cannot be extended.
  • super: refers to the parent class.
  • Access modifiers: private, default (package-private), protected, public.

7. Strings

String objects are immutable: once created, they cannot change. Operations like concatenation create new strings. For building strings in loops, use StringBuilder, which is mutable and much more efficient.

StringBuilder sb = new StringBuilder();
for (int i = 1; i <= 5; i++) {
    sb.append(i).append(" ");
}
System.out.println(sb.toString().trim());   // 1 2 3 4 5

Also know the difference between == (compares references) and .equals() (compares content), and how the string constant pool works.

8. Exception handling

Exceptions handle errors without crashing your program.

  • Checked exceptions (such as IOException) must be handled or declared with throws.
  • Unchecked exceptions (such as NullPointerException and ArithmeticException) extend RuntimeException.
  • try, catch, finally, and try-with-resources for automatically closing files and connections.
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Cannot divide by zero");
} finally {
    System.out.println("Always runs");
}

9. Arrays and the Collections Framework

Arrays have a fixed size. The Collections Framework provides flexible data structures: List (ArrayList, LinkedList), Set (HashSet, TreeSet) and Map (HashMap, TreeMap). Learn when to use each; this is one of the most asked interview areas. See our full guide to the Java Collections Framework.

10. Generics

Generics make code type-safe and reusable: List<String> can only hold strings, so errors are caught at compile time instead of run time.

11. Multithreading basics

Threads let a program do multiple things at once. Learn to create threads by extending Thread or implementing Runnable, use ExecutorService for thread pools, and protect shared data with synchronized. Understand common problems such as race conditions and deadlocks at a conceptual level.

12. Java 8 and modern features

  • Lambda expressions: short, anonymous functions.
  • Functional interfaces: interfaces with a single abstract method, such as Predicate and Function.
  • Stream API: process collections declaratively.
  • Optional: represent values that may be absent.
  • Newer additions: var, records, text blocks and switch expressions in later versions.
List<Integer> marks = List.of(45, 82, 67, 91, 38);
List<Integer> passed = marks.stream()
        .filter(m -> m >= 40)
        .sorted()
        .toList();
System.out.println(passed);   // [45, 67, 82, 91]

13. Memory management and garbage collection

Java manages memory automatically. Objects without references are cleaned up by the garbage collector. Know the difference between stack memory (method calls and local variables) and heap memory (objects).

How to study these concepts

  1. Learn one concept a day and write three small programs using it.
  2. Explain each concept aloud, as if in an interview.
  3. Build a small project, such as a library management console app, that uses OOP, collections and exceptions together.
  4. Practise with Java interview questions.

===FAQ=== Q: What are the most important Core Java topics for interviews? A: OOP principles, strings, exception handling, the Collections Framework, multithreading basics, Java 8 features such as streams and lambdas, and the difference between JDK, JRE and JVM. Q: How long does it take to learn Core Java? A: Most beginners need about six to ten weeks of regular practice to become comfortable with Core Java concepts. Q: Is Core Java enough to get a job? A: Core Java is the foundation, but most jobs also require SQL, a framework such as Spring Boot, Git and, for full stack roles, front-end skills. Q: What is the difference between == and equals() in Java? A: The == operator compares whether two references point to the same object, while equals() compares the content of objects when the class overrides it, as String does.

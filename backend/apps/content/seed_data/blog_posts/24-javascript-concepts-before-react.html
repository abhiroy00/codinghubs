Many beginners jump into React and soon feel lost. The reason is usually not React itself; it is JavaScript. React code is full of arrow functions, destructuring, array methods and promises. If you understand the JavaScript concepts before React covered here, React becomes far easier to learn.

1. let, const and block scope

Use const by default and let when a value needs to change. Avoid var, whose function scope causes confusing bugs.

const course = 'React';
let lessonsDone = 3;
lessonsDone += 1;

Note that const prevents reassignment, not mutation: you can still change the contents of a const array or object.

2. Arrow functions

const double = (n) => n * 2;
const greet = (name) => {
  const message = `Hello, ${name}`;
  return message;
};

React components and event handlers use arrow functions constantly. Know the implicit return (no braces) and that arrow functions do not have their own this.

3. Template literals

Backticks let you embed variables: `Welcome, ${user.name}!`. You will use them for class names, URLs and messages.

4. Objects and arrays

Be comfortable creating, reading and updating nested objects and arrays, because React state is usually made of them.

const student = { name: 'Riya', skills: ['HTML', 'CSS'], address: { city: 'Delhi' } };
console.log(student.address.city);

5. Destructuring

const { name, address: { city } } = student;
const [first, second] = ['React', 'Node'];

// in React
function Profile({ name, city }) { /* ... */ }
const [count, setCount] = useState(0);

Props and hooks rely on destructuring, so this one is essential.

6. Spread and rest operators

The spread operator ... copies arrays and objects, which is how you update React state without mutating it:

const updated = { ...student, name: 'Riya Sharma' };
const moreSkills = [...student.skills, 'JavaScript'];

function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}

7. Array methods: map, filter, reduce, find

const courses = [
  { title: 'Python', price: 15000, live: true },
  { title: 'Java', price: 18000, live: false },
  { title: 'React', price: 16000, live: true },
];

const titles = courses.map((c) => c.title);
const liveCourses = courses.filter((c) => c.live);
const total = courses.reduce((sum, c) => sum + c.price, 0);
const java = courses.find((c) => c.title === 'Java');

In React, map renders lists and filter removes items from state. You will use these every day.

8. Truthy, falsy and short-circuiting

Values like 0, '', null, undefined and NaN are falsy. React uses && and the ternary operator for conditional rendering:

{isLoggedIn && <Dashboard />}
{items.length > 0 ? <List /> : <EmptyState />}

Be careful: {items.length && <List />} renders 0 when the list is empty. Compare explicitly instead.

9. Optional chaining and nullish coalescing

const city = user?.address?.city ?? 'Not provided';

These prevent crashes when data has not loaded yet, which happens often with API calls.

10. Modules: import and export

// utils.js
export const formatPrice = (n) => `₹${n.toLocaleString('en-IN')}`;
export default function slugify(text) { /* ... */ }

// App.jsx
import slugify, { formatPrice } from './utils.js';

Every React file imports and exports components, so understand default versus named exports.

11. Closures and scope

A closure is a function that remembers variables from where it was created. React hooks and event handlers depend on closures, and "stale closures" are a common source of bugs.

function makeCounter() {
  let count = 0;
  return () => ++count;
}
const next = makeCounter();
next(); // 1
next(); // 2

12. The this keyword (briefly)

Modern React uses function components, so you rarely deal with this. Still, understand how it works in regular functions, methods and arrow functions, because interviews ask about it and older codebases use class components.

13. Asynchronous JavaScript

Data fetching in React depends on promises and async/await:

async function loadCourses() {
  try {
    const res = await fetch('/api/courses');
    if (!res.ok) throw new Error('Failed to load');
    return await res.json();
  } catch (error) {
    console.error(error.message);
    return [];
  }
}

Also understand the event loop at a basic level: why code after await runs later, and why setTimeout does not run immediately.

14. Immutability

React decides whether to re-render by checking if state changed. If you mutate an array with push and set the same array back, React may not notice. Always create new arrays and objects:

setTodos([...todos, newTodo]);                      // add
setTodos(todos.filter((t) => t.id !== id));        // remove
setTodos(todos.map((t) => t.id === id ? { ...t, done: true } : t));   // update

15. DOM and events basics

React abstracts the DOM, but knowing how events, forms and preventDefault() work in plain JavaScript helps you understand what React does for you.

How to practise

  1. Build a to-do list in plain JavaScript using array methods and immutable updates.
  2. Fetch data from a public API and display it with map.
  3. Rewrite the same app in React and notice how familiar it feels.

===FAQ=== Q: How much JavaScript should I know before React? A: You should be comfortable with functions, arrow functions, arrays and objects, destructuring, spread, array methods, modules and async/await. You do not need to master every advanced topic. Q: Can I learn JavaScript and React at the same time? A: You can, but it is harder. Spending a few weeks on JavaScript fundamentals first usually makes learning React faster overall. Q: Which JavaScript array methods are used most in React? A: map is used to render lists, filter to remove items, find to locate an item, and reduce occasionally for totals. Q: Do I need to learn classes before React? A: Not necessarily. Modern React uses function components and hooks, but understanding classes helps when reading older code.

## Contract and dependency order

1. Foundation: isolated Python/React projects, immutable free-only configuration, local PostgreSQL + pgvector, migrations, hardware profiles and native service scripts. Verify real migration, restart persistence and health.
2. Identity: password hashing, server-side cookie sessions, CSRF/Origin/Host checks, first-owner setup, separate user tenants and site ownership. Verify unauthenticated access, cross-tenant denial, login throttling and invalid input.
3. Ingestion: bounded CSV/XLSX uploads, exact source provenance, date/filter coverage, snapshot deduplication, OAuth PKCE/state and encrypted Google tokens. Verify supplied seven-file workflow, duplicate import, missing dates and quota pauses. No fabricated joins.
4. Technical analysis: DNS-pinned public-only HTTPX crawler, robots/sitemap bounds, persistent frontier/history, cancel/pause/resume, content hashes and link graph. Verify a controlled transport fixture and permitted public GET crawl.
5. Intelligence: measured keyword/CTR/ranking cohorts, explicit scoring assumptions, twenty independent persisted agent states, daily actions, reports, comparisons and imported competitor/backlink/referral evidence. Verify available data and honest blocked states.
6. Local AI/RAG: explicitly installed small Ollama models, benchmark, structured bounded drafts, local embeddings/cache, versioned tenant-filtered hybrid retrieval, deterministic fallback; manual ChatGPT export/import. Verify local inference, retrieval isolation and hostile imported output.
7. Implementation proposals: registered local repository roots, exact-hash/unique-replacement diff, owner approval, clean-tree feature branches, fixed tests and guarded rollback. Verify using disposable local Git fixtures. No automatic push/deploy.
8. Automation/operations: durable due slots in Asia/Kolkata, bounded missed-run catch-up, local notifications, native worker/scheduler plus optional Celery/Valkey, private metrics, backups and restore tests. Verify shutdown/restart recovery and backup reconstruction.
9. Dashboard: React/TypeScript/Tailwind/Recharts with real authenticated API, multi-site selector, import, actions, crawl controls, knowledge, ChatGPT exchange, integrations, schedules and policy/resources. Verify browser flows at desktop/mobile, keyboard/errors and production build.
10. Integration: focused tests per slice, full relevant platform suite, real PostgreSQL/runtime/browser/model evidence, dependency audit, six requested root documents and honest implementation matrix.

## Trust boundaries

User uploads/pages/model output are data only. SSRF guards pin resolved public IPs and validate each redirect. No model has filesystem, Git, Google write or shell authority. Every site/job/document/query/proposal lookup is tenant-scoped. Secrets are encrypted locally; raw uploads and runtime state are ignored/private. Source edits require a separate human approval and reject stale hashes/symlinks/sensitive paths. Daily jobs do not run while the computer is off. Existing hosting expenditure is outside this new app's local charge meter and is never claimed to be zero.

## Verification checkpoints

Each slice needs a functioning public seam and failure tests before broadening. Installation is explicit and free; no application-triggered model/package downloads. Lightweight profile runs first on the detected M1/8GB host. Optional heavyweight services remain documented as optional if not exercised. External credential-dependent workflows are marked unverified, never simulated as live success.

# Project showreel

User-supplied video, added on 19 November 2026. The original file is
`WhatsApp Video 2026-11-13 at 23.09.05.mp4`.

The website copy preserves the full 30-second duration and original audio, encoded
as 1280 × 720 H.264 (yuv420p) with AAC audio, CRF 25 and MP4 fast start. The WebP
poster is extracted from the same video at two seconds. No external assets are used.

Playback is muted by default, with native sound, playback and fullscreen controls.
Automatic playback pauses off-screen and in background tabs. Reduced-motion users
can start playback manually.
